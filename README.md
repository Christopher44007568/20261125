# Stereo Decal Scale Lab

这个模块用 Go 标准库模拟并记录：低采样区中的定向贴花、接触阴影和细节法线是否仍保持世界尺度，以及独立逐眼采样、世界共享采样和直接复制单眼切线结果之间的差异。

不依赖第三方 Go 包，也不需要安装图像或数学组件。

## 运行

```sh
go test ./...
go run ./cmd/decallab
```

默认写入 `artifacts/decallab/`：

- `report.json`：完整机器可读报告。
- `report.md`：中文汇总和 13 项判定。
- `normal_probes.csv`：法线探针、切线/世界法线、LOD、波长和采样间距。
- `decal_scales.csv`：贴花 UV、米制宽高、曲面雅可比尺度和共享单元键。
- `shadow_edges.csv`：阴影边理论半径、稀疏采样半径、偏差和过渡宽度。
- `binocular_diff.csv`：同像素双眼射线、视差位移、切线复用法线误差和光照差。

输出单个 JSON 到标准输出：

```sh
go run ./cmd/decallab -out -
```

若必需检查失败，CLI 会在写完报告后以状态码 `1` 退出。

## 直接结论

当前确定性场景的 `go test ./...` 与 CLI 均通过，报告中的结果支持以下口径：

- **世界尺度不会因低采样密度本身改变**：贴花宽高、阴影边半径和法线主波长都以“米”或“周期/米”定义；高/低采样在同一世界点得到相同尺度。
- **低采样会降低可检测性，而不是授权重缩放**：稀疏步长会增大阴影边插值误差，共享格点会增大量化误差，过密法线 octave 会触发 LOD；这些量都逐探针记录。
- **正确共享必须是世界锚定并重投影**：共享单元按贴花局部米制坐标分键，双眼可以复用同一格点结果；位置误差被限制在单元对角线内。
- **单眼切线空间结果不能直接复制到另一眼**：斜视角和曲面会让同一显示像素对应不同世界命中点。当前负对照测得最大切线法线误差约 `10.96°`、贴花重投影误差约 `0.0476 m`。
- **光照必须按眼的观察向量重新着色**：共享世界光源相同也会有视角相关高光差异；`eye_specific` 场景还显式测试冷暖、方向和强度均不同的双眼光源。

## 场景覆盖

| 场景 | 覆盖点 |
|---|---|
| `curved_oblique_shared` | 球面、定向箭头贴花、62.6° 斜视、共享米制格点、曲面尺度雅可比 |
| `transparent_oblique_two_sided` | 透明玻璃平面、57.1° 斜视、背面命中、双面 UV、共享采样 |
| `split_eye_lighting_material_lod` | 曲面、左右眼不同光源、暖/冷光照差、LOD0→LOD2 |
| `grazing_very_low_sampling` | 73.7° 掠射、16 像素步长对应的低世界采样间距、LOD2 和更大复制误差 |

每个场景包含 4–5 个命名探针，覆盖中心、U/V 边缘、斜角和曲面包裹位置。

## 建模约定

### 贴花

`Decal.WidthM`、`Decal.HeightM` 和方向轴均为世界米制。UV 从世界位置投影到贴花方向轴：

```text
u = 0.5 + dot(p - center, axis_u) / width_m
v = 0.5 + dot(p - center, axis_v) / height_m
```

报告同时记录投影尺寸和目标曲面局部雅可比对应的弧面尺寸。曲面造成的弧面拉伸是预期几何现象；检查项要求它不随眼别、采样密度或 LOD 漂移。

### 独立逐眼采样

每只眼睛有自己的位置、朝向、投影矩阵和像素射线。规范世界探针会分别投影到左右眼，再从每眼像素反投射线并与表面求交。命中误差约为浮点精度，说明记录的是该眼自己的表面点和 TBN。

### 共享世界采样

`WorldSampleCache` 使用贴花锚点的 `AxisU` / `AxisV`，按 `SharedCellM` 建立表面局部二维米制单元。共享样本在单元中心求值；曲面会通过大圆/平面弧长映射回到表面。它不是按屏幕像素或眼别缓存。

### 单眼复制负对照

对每个左眼投影像素，右眼使用**相同像素坐标**发射自己的射线，得到不同的 `RightSamePixelPoint`。随后把左眼的：

- 切线空间法线值放到右眼命中点的 TBN；
- 贴花 UV/尺度当作右眼结果；
- 接触阴影 alpha 和左眼着色直接搬用。

`CopyComparisonRecord` 记录这些操作的法线角度、米制 UV 重投影、阴影 alpha 和辐射度误差。中心/视轴重合探针可能误差较小，因此判定按场景捕获最大误差，而不是要求每个探针都误判。

### 细节法线和 LOD

细节法线 octave 使用 `WavelengthM`，频率为 `1 / wavelength_m` cycles/m。LOD0 有粗/中/细三层，LOD1 移除最细层，LOD2 只保留 `0.120 m` 主波长。LOD 切换会改变扰动角，但保留层的波长和贴花尺度不变。

自动 LOD 使用 Nyquist 保守条件：

```text
wavelength_m >= 2.2 * sample_spacing_m
```

不满足的 octave 会被移除，并在 `undersampled_octaves` 中记录。

### 接触阴影

接触阴影是米制椭圆，`ExpectedEdgeRadiusM` 是指定方向上的解析半边半径。稀疏测量从中心按采样步长扫描 alpha=50% 的位置并做线性插值；检查要求：

- 每个方向恰好找到一个下降沿；
- 插值偏差不超过一个采样步长；
- 同一方向的理论世界半径不随密度改变。

## 判定口径

`report.json` 中有 13 个检查，关键不变量包括：

- 每眼射线重投影误差 `< 1e-7 m`。
- 贴花标称宽高误差 `< 1e-12 m`。
- 高/低采样的曲面尺度差 `< 1e-7%`。
- 共享格点误差与单元对角线之比 `<= 1`。
- 阴影边偏差/采样步长 `<= 1`。
- 主法线波长在所有 LOD 中一致。
- 每个场景的最大双眼像素差 `> 2 px`。
- 每个场景都必须捕获直接复制单眼切线结果的负对照。
- 至少两个场景达到 45° 斜视，其中一个达到 60°。
- 分光场景的辐射距离 `>= 0.15`。
- 低采样探针必须实际触发 LOD1/LOD2。
- 透明场景必须完成背面命中和 UV 记录。

这些阈值是实验室回归口径，不是产品画质验收阈值；接入真实渲染器时，可把同一组结构和 CSV 记录替换为 GPU readback、PIX/RenderDoc 导出或覆盖率统计。
