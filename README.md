# Clearcoat BRDF Energy Audit

Go 标准库实现的 clearcoat BRDF 能量审计，不依赖第三方渲染或数值库。

## 材质组

- `rough_metal`：粗糙金属，基底 `F0=0.95`、粗糙度 `0.42`、无漫反射，涂层 `F0=0.04`。
- `clear_dielectric`：透明涂层下的粗糙电介质，基底 `F0=0.04`、漫反射反照率 `0.65`、粗糙度 `0.28`。
- `energy_limit`：接近能量上界的电介质，漫反射反照率 `0.96`、粗糙度 `0.18`，用于放大约束失效。

每组都在 `0°`、`60°`、`89°` 视角、普通/黑色底材、1 盏和 3 盏单位辐照光源下评估。黑色底材将基底 `F0` 与漫反射都置零，只允许透明涂层自身反射。

## 模型

- 镜面 lobe 使用 GGX NDF、Smith 高度相关遮蔽项、Schlick Fresnel 和 GGX 重要性采样。
- 入射透射权重为 `T_i = 1 - F_coat(theta_i)`。
- 出射透射权重为反射方向上的平均 `T_o = 1 - F_coat(theta_o)`。
- 涂层自身能量为 `F_coat(theta_i)`。
- 共享预算路径令漫反射使用 `1 - E_spec` 的剩余预算，避免漫反射和镜面重复统计同一入射能量。
- 错误路径将镜面 lobe 归一化到单位方向反照率，同时保留完整漫反射反照率，复现白色高光凭空增亮。

当前模型只记录涂层的一次透射和一次出射；忽略涂层和基底之间的多次内部反弹会低估能量，不会制造超过输入上界的能量。

## 运行

```bash
go test ./...
go run .
```

程序生成：

- `energy_audit.csv`：全部材质、视角、黑底和多光照组合的逐项能量。
- `audit_report.txt`：终端摘要和所有超过输入上界的像素原因。

## 关键结果

- 共享预算路径在所有组合下满足 `total_energy <= lights`。
- 粗糙金属只有镜面 lobe，错误归一化会提高白高光，但仍低于上界。
- 透明电介质和能量极限材质在错误路径下超界；原因是镜面被补到单位能量，而漫反射没有扣除镜面已占用的预算。
- `89°` 掠射角下涂层 Fresnel 接近 1，进入基底的透射权重很小，因此错误路径的超界量显著缩小。
- 黑色底材不会超界：基底吸收全部透射能量，像素只剩涂层 Fresnel 反射。
- 三盏灯的上界是 3；BRDF 对光源线性，错误路径的单像素超界量也近似放大三倍。
