## 异步重投影资源依赖图与屏障验证

纯 Go 标准库实现，无外部依赖。固定一个异步重投影任务（T2）与主渲染
共享纹理的读写关系，构建资源依赖图（提交者、使用者、读写类型、队列、
屏障），并在执行时间线上验证屏障——完成顺序不等于提交顺序。

- `types.go`：资源、访问、任务、边、屏障等基础类型
- `graph.go`：依赖图构建（含显存别名传播）与队列时间线模拟
- `validate.go`：RAW/WAR/WAW/取消后引用检测与屏障覆盖判定
- `schemes.go`：单队列、双队列、显存别名三种方案及故障注入
- `main.go`：报告输出；`validate_test.go`：行为测试

运行：

```sh
go run .    # 打印三种方案的依赖图、屏障表与验证报告
go test ./...
```
