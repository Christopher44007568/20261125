## 多频图层合成器模拟

这个 Go 程序用确定性时间轴模拟三个不同刷新节奏的输入层：

- `world`：90 Hz，每个显示 tick 提交一帧。
- `ui`：45 Hz，每两个显示 tick 提交一帧，并在 tick 8、10 暂停。
- `hand`：30 Hz，每三个显示 tick 提交一帧，包含迟到和重复提交。

时间以显示 tick 为单位，1 tick 等于 1/90 秒。程序不使用真实定时器或第三方依赖，只使用 Go 标准库。

### 三种策略

- 独立刷新：每个显示 tick 都取各层最新帧；旧帧继续使用并记录年龄，不等待低频层。
- 统一等待：只有所有层都有尚未合成的新序列时才输出，任一层落后都会阻塞整个显示 tick。
- 过期层复用：任一层带来新帧即可输出，其他层复用旧帧并标明年龄；暂停、迟到或重复提交不会阻塞输出。

每个合成帧都记录：

- 帧来源：层名、帧序号、提交 tick、生产时间和可用时间。
- 图层年龄：当前显示时间减去帧可用时间。
- 来源状态：`fresh`、`reused`、`paused`、`late`、`late-paused` 或 `duplicate`。
- 画面差：与上一帧相比内容发生变化的图层，以及整帧 FNV-1a 摘要。

### 运行

```bash
go run .
go test ./...
```

当前场景中，独立刷新和过期层复用都产生 13 个显示输出且没有阻塞 tick；统一等待只产生 4 个输出，并记录 9 个阻塞 tick。
