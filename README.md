# 薄壳法线偏置与凹角自交诊断

纯 Go、仅标准库实现的薄壁 L 形弯板法线偏置示例。程序把圆角弯头
沿法线向内偏置到指定距离，保留全部三角形，并输出外表面、内表面与
带缺陷标注的切面 PPM。

默认参数：

- 偏置距离：`2.00 mm`
- 弯头半径：`1.25 mm`
- 直臂长度：每臂 `18.00 mm`
- 挤出高度：`12.00 mm`
- 四分之一圆弧分段：`48`

## 运行

```bash
go run .
```

产物写入 `artifacts/`：

- `outer.ppm`：凸侧外表面
- `inner.ppm`：法线内偏置表面，反转段标红
- `section.ppm`：`Z=0` 切面、凹角放大图、自交环与反转三角形
- `report.json`：拓扑、体积、诊断与滑移扫描结果
- `volume_curve.csv`：`0..3 mm`、`0.025 mm` 步长的体积曲线

可用参数覆盖默认设置，例如：

```bash
go run . -offset 2 -corner-radius 1.25 -arc-segments 48 -out artifacts
go test ./...
```

## 几何与诊断

外轮廓由两条长度 `18 mm` 的直臂和半径 `1.25 mm` 的四分之一圆弧组成。
内轮廓按逐点精确法线向内偏移。偏移量略大于圆角半径时，直臂的偏置段
在凹角处交叉：

- `1.250 mm` 时内圆弧退化为一点；
- `1.275 mm` 起出现 1 个自交环；
- `2.000 mm` 时切面有 48 个反转三角形和 1 个自交环。

切面三角形按两三角形/分段固定连接。反转判断比较三角形有向面积与
直臂预期方向，仅染色，不删除、不裁剪、不重新三角化。内表面渲染同样
只替换颜色。

## 连续性

网格始终为 `204` 顶点、`404` 三角形、`606` 条边，边界边和异常边均为
零。体积由闭合网格的有符号四面体和得到，因此偏移增大时由同一组
三角形连续求值。`report.json` 同时给出离散网格体积与光滑解析体积：

```text
V(d) = H * (2 * ArmLength * d + pi/2 * (CornerRadius*d - d*d/2))
```

默认 `d=2 mm` 时：

- 网格体积：约 `873.423095853 mm^3`
- 解析体积：`873.424777961 mm^3`
- 滑移扫描最大一阶差分：约 `11.383054056 mm^3`
- 三阶差分仅为浮点舍入量级

实现中没有局部删除、洞穴填补或按偏移重新封闭等操作；自交和反转作为
可见几何缺陷保留在报告中。
