## hairaa：亚像素发丝的解析覆盖率

纯 Go 标准库实现（`go.mod` 无任何外部依赖），解决直径不足一个像素的
发丝在动画中闪成亮线的问题。

### 问题根因

单点采样（命中像素中心即整像素不透明）没有覆盖率概念：亚像素发丝
随亚像素平移时，每个像素只在“全亮 / 全灭”之间跳变，于是出现闪烁亮线。
把半径加粗到 0.5px 能暂时压住闪烁，但几何被永久放大，不是抗锯齿。

### 实现方法

- 发丝建模为中心线折线，每段按真实亚像素半径膨胀为有向带状四边形
  （`geom.go` 的 `ribbonQuad`），平接头。
- 解析覆盖率：对每个像素矩形 `[x,x+1)×[y,y+1)` 用 Sutherland–Hodgman
  做逐像素几何裁剪（`clipRect`），裁剪多边形面积（鞋带公式）即该像素
  的覆盖率 alpha，取值严格落在 `[0,1]`。
- 多段交叠按 `1-(1-a)(1-b)` 合并，不会相加超 1，也不会被抹成硬边。
- 对比基线：`ModeBinary`（半径不变的单点采样）与 `ModeThick`
  （半宽强制 0.5px 的加粗采样），三者共用同一套几何与场景。
- 覆盖率直接作为 alpha 与背景做 source-over 混合；输出放大一律最近邻，
  不做后处理平滑。

### 产物（`go run .` 后写入 `out/`）

- `closeup.png`：8×8 逻辑像素放大 56 倍的近景，三栏分别是二元采样、
  加粗采样、解析覆盖率（标注每像素 alpha 与真实带状轮廓）。
- `filmstrip.png`：64×40 画面、16 帧亚像素平移的远景连续帧，
  上排二元、下排解析。
- `flicker.png`：逐像素时序覆盖率极差热力图（二元 / 解析 / 二者差值）。
- `stats.csv`：逐帧总覆盖率、点亮像素数、最小覆盖率，以及极差均值、
  跳变次数和总覆盖率变异系数。

### 验证

`go test ./...` 覆盖：裁剪面积之和等于真实带状面积、亚像素发丝在整段
平移周期内不被完全抹掉且不产生全不透明像素、二元模式存在逐帧跳变而
解析模式零跳变、加粗模式面积超出真实几何、内部平移下覆盖率守恒。

当前量化结果（见 `out/stats.csv`）：16 帧总覆盖率变异系数
二元 0.0563、解析 0.0016；相邻帧跳变二元 295 次、解析 0 次。
