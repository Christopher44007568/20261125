# BRep 三方向剖切与截面闭合校验

纯 Go 标准库实现（无任何第三方依赖）的多面体 BRep 剖切系统。对同一个实体
沿三个不同方向剖切，提取截面曲线、缝合为闭合轮廓，并校验闭合性、嵌套层序、
朝向一致性和自交，最终输出实体剖切图、二维截面拼图和端点误差热图。

## 功能

- 同一个 BRep 沿三个方向剖切：轴向正交切、与圆孔精确相切的正交切、过质心斜切。
- 截面曲线逐面求交，正确处理面上顶点、共面边、单点相切、孔环穿越等病态情形。
- 端点空间哈希吸附、重复边合并、共线小面链合并、最小转角环行走。
- 闭合检查（偶度节点 + 端点簇残差）、嵌套层序、同层朝向一致性、严格自交检测。
- 双精度管线与 float32 降精度应力管线对照，量化端点闭合残差。
- 仅用 `image`、`image/png`、`math` 等标准库软件光栅化输出三张 PNG。

## 目录结构

- `geom/`：三维/二维向量、剖切平面与正交坐标基、包围盒。
- `brep/`：BRep 数据结构、带孔多边形拉伸构建、边邻接表、示例实体。
- `section/`：截面提取、端点吸附缝合、共线合并、环行走、闭合与自交校验。
- `render/`：画布、5x7 点阵字库、jet 热图色带、三种图像渲染器。
- `main.go`：编排三方向剖切、双精度运行和图像/文本报告输出。

## 运行

```bash
go run .
```

输出写入 `artifacts/`：

- `solid_cutaway.png`：三个方向的实体剖切图（画家算法面着色 + 红色截面 + 半透明剖切平面）。
- `section_montage.png`：二维截面拼图，上行 float64、下行 float32，含孔填充与层序标签。
- `endpoint_error_heatmap.png`：端点误差热图，高斯斑点 + jet 色带 + 每面板色标。

测试：

```bash
go test ./...
```

## 示例实体覆盖的病态几何

- 尖角：楔形外角与三角形通孔的尖锐角点。
- 斜切过孔：40 边细分圆柱通孔，斜切面在孔壁产生密集穿越点。
- 相切：圆角凸台首段与直墙共线；剖切平面与圆柱孔精确相切。
- 共面分裂面：底边在 x=5 处分裂为两段，拉伸后得到两个精确共面侧壁。

## 关键算法

- 逐面事件行走：按顶点有向距离的符号变化维护环内/外状态，面上顶点游程
  （on-plane run）作为成对出入事件，单点相切不破坏交替配对。
- 材料判别：外环穿越弦只要求落在外环内（可跨越孔），孔环穿越弦直接保留为
  孔边界，边界边绕过材料中点测试。
- 端点吸附：容差随包围盒对角线缩放，空间哈希近邻合并，记录每簇最大残差。
- 共线合并：仅在度为 2 且两边夹角低于阈值时消除节点，真实角点不受影响。
- 自交检测：逐对非相邻边做严格内部相交判定，共线重叠不计为自交。
- 层序：严格奇偶内点测试计算嵌套层级，避免相切/接触环被误判为嵌套。

## 精度应力对照

float32 模式对坐标、平面方程乘法/加法、交点插值和平面投影逐项做单精度
舍入。精确连接点残差保持为 0，斜切交点出现约 1e-8 量级残差，但仍低于该模式
的闭合容差，因此所有方向在两种精度下均报告闭合、层序一致且无自交。
