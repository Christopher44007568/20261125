# 自适应有理 Bézier 曲面细分

纯 Go 标准库实现。没有引入 CAD、几何内核或图像库。

## 运行

```bash
go test ./...
go run ./cmd/adaptivebezier -out artifacts
```

程序会生成 7 张 PPM（P6）和三档指标：

- `artifacts/adaptive_mesh.ppm`：1500×720 拼图；上排线框、下排实体；三列依次为 `0.50 / 0.15 / 0.05 px`
- `artifacts/lod0_tol0.50_{wire,solid}.ppm`
- `artifacts/lod1_tol0.15_{wire,solid}.ppm`
- `artifacts/lod2_tol0.05_{wire,solid}.ppm`
- `artifacts/metrics.json`、`artifacts/metrics.txt`

## 实现

曲面采用带权控制网的 bicubic rational Bézier 片：

```text
P(u,v) = Σ Bi(u) Bj(v) wij Pij / Σ Bi(u) Bj(v) wij
```

裁剪域由两条线性边和两条二次有理曲线边组成，并验证为凸域。流程如下：

1. 裁剪边按三维弦长误差自适应采样，误差统一换算成屏幕像素。
2. 参数域被 `12×12` 单元裁剪。凸多边形求交保留裁剪环上的全部采样点，因此裁剪边不会退化成横切弦。
3. 每个裁剪片按面积质心扇形三角化；统计结果保留三角形、四边形及更高阶裁剪片数量。
4. 对弦高超标的三角形采用共形 red-green 细分。所有边中点由全局边缓存产生，相邻三角形共享同一顶点；裁剪边不拆分。
5. 统计所有三角形共用边。内部边应被恰好两个三角形使用，裁剪边应被一个三角形使用；否则计入裂缝。

## 指标定义

- 最大弦高：在三角形内按重心网格采样精确曲面，计算采样点到三角平面的法向距离，再乘固定投影比例（像素）。审计采样密度高于细分采样密度。
- 轮廓误差：裁剪边界采样段与精确有理边界之间的最大屏幕垂距。
- 裂缝长度：所有拓扑价数异常的网格边屏幕长度之和。

## 当前结果

| 容差 (px) | 三角形 | 边界段 | 裁剪片 T/Q/N | 最大弦高 (px) | 轮廓误差 (px) | 裂缝 (px) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 0.50 | 453 | 89 | 2/2/32 | 0.429908 | 0.166531 | 0 |
| 0.15 | 1555 | 147 | 2/1/34 | 0.120496 | 0.041613 | 0 |
| 0.05 | 5994 | 256 | 1/1/35 | 0.042914 | 0.010420 | 0 |

三档均 `watertight=true`，且每档都同时含三角形与四边形裁剪片。边界段从 89 增至 256，轮廓误差从 0.167 降至 0.010 像素，说明收紧容差同时改变了几何轮廓，而不只是增加内部三角形。
