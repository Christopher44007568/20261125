# Highlight Lab

一个只用 Go 标准库实现的镜面高光时间重采样实验台。它不重投影整个基础画面，
只跟踪高光的中心、峰值、拉伸长度与能量，并用每只眼睛独立的历史记录合成。

## 运行

```bash
go run . -addr 127.0.0.1:8080
```

打开 <http://127.0.0.1:8080>。没有第三方 Go 依赖，也不需要 npm 或外部字体。

```bash
go test ./...
```

## 三个场景

- **Rough Metal / 旋转**：拉丝粗糙金属盘旋转，高光中心绕行，拉伸长度随各向异性
  方向变化，峰值与投影面积互相交换。
- **Mirror Sphere / 平移**：铬球平移时使用当前视点重新计算半程向量，高光会相对球心
  移动；左右眼的反射方向因此不同。
- **Glass / 物体运动**：玻璃沿二维路径滑动并轻微转动，折射高光随物体位置和朝向变化。

所有运动都是确定性的 60 FPS 时间线。Go 在 `/api/timeline` 一次生成完整双目标
时间线，浏览器只负责绘制，不参与物理或历史计算。

## 历史规则

- 历史映射的键是 `(eye, object)`。左眼永远不能读取右眼记录，右眼也不能读取左眼。
- 每条历史只保存高光中心、峰值、拉伸/厚度、方向和能量，不保存物体变换、深度或
  全屏运动矢量，因此不存在基础 timewarp。
- 重采样权重由当前中心与上一帧高光中心的高斯重叠计算。最终峰值和能量使用凸组合，
  并显式限制在 `max(current, sampled)` 与 `1.0` 以内，因此不会逐帧相加到过曝。
- 审计字段会报告 `crossEyeSamples`、`energyCapViolations` 和
  `fullFrameTimewarps`；正常情况下三项均为 0。

## 记录与调试

- `GET /api/timeline`：完整 JSON 时间线，包含逐帧双目标记录和审计汇总。
- `GET /api/ledger.csv`：导出的高光台账，含位置、拉伸、峰值、能量、历史来源、
  合成能量和上限标记。
- 页面底部可暂停、逐帧、拖动时间线以及切换左右眼；`T−1 GHOST` 只显示上一帧高光
  轮廓，用于检查跟踪，不参与成片画面。
- 可分享的调试地址示例：
  `/?frame=200&paused=1&eye=R&object=mirror-sphere`。

## 目录

- `main.go`：HTTP 服务、时间线 JSON 与 CSV 导出。
- `sim/scene.go`：三场景运动、双目标反射与时间线构建。
- `sim/history.go`：稀疏历史重采样、能量约束与审计。
- `web/`：嵌入二进制的无依赖 Canvas 界面。
