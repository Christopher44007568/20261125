# MESHSCOPE · 零件网格特征识别

一个仅使用 Go 标准库的网格特征检查器。服务端生成三组故障样件网格，直接从三角面法线、邻接关系、曲率中心和最小二乘拟合中识别平面、圆柱、孔与圆角；浏览器端用原生 WebGL 把分类色叠加到带光照的实体渲染上。

## 运行

```bash
go run .
```

打开 <http://localhost:8080>。可指定监听地址：

```bash
go run . -addr 127.0.0.1:9090
```

Go 之外没有依赖；前端不使用框架、CDN 或外部 WebGL 库。

## 三组故障形态

- `01 邻接圆角链`：两段相切圆弧在切点共享法线但曲率中心相反。分类器按局部圆柱中心与 G1 边界拆分，避免把两个圆角并成一个区域。
- `02 倾斜贯穿孔`：28° 斜轴贯穿板件，上下口分别是真实的斜圆柱/平面交线椭圆；另有一个竖直圆柱凸台作为 `CYLINDER` 参照。
- `03 近似平面盖板`：三组浅坡度分面落在同一宏观平面附近，保留亚毫米级形貌误差并显示低置信区域接缝。

## 分类流程

1. 三角面拓扑按量化边焊接，允许不同曲面在相切处共享几何边。
2. 对每个面建立二环平滑邻域，用法线协方差拟合圆柱轴，用带符号法方程求轴心与半径。
3. 先增长圆柱类区域，再增长平面区域；圆形区域的角覆盖范围、带符号径向法线和边界平面数决定 `CYLINDER`、`HOLE`、`FILLET`。
4. 用平面方程合并同面区域，同时保留低置信的相切换线。
5. 每条分类边界按两侧拟合置信度、二面角与相切程度计算边界置信度；锐利孔口边界高，相切圆角缝与近平面接缝低。
6. 几何审计使用主平面作为基准，保留面的带符号形貌偏差；圆柱/孔/圆角使用径向残差。

## 渲染与检查

- `分类叠加`：每种特征独立颜色，但颜色只调制实体材质的亮度，方向光、高光、轮廓和遮挡仍参与着色。
- `几何审计`：分类色替换为带符号误差热图和等值线，几何起伏不会被特征色盖住。
- `分屏`：同一实体左侧分类、右侧误差热图，直接对照。
- 边界线颜色从橙红（低置信）过渡到青白（高置信），3D 标注直接投影到对应边界并显示数值；高亮旁的 `Δ FORM` 标注保留几何误差。
- 可调分类覆盖强度、开关边界/等值线、轨道旋转、滚轮缩放和自动旋转。
