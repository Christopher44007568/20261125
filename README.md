# 闭合椭圆管扫掠标架对比

纯 Go 标准库实现，不依赖外部包。程序沿闭合三叶结等弧长采样，分别构造：

- Frenet 标架：由解析一阶、二阶导数直接得到法向和副法向。
- 平行传输标架：逐段旋转到下一切线，并对闭合 holonomy 做均布校正。
- 固定参考标架：动态选择与所有切线保持最大非平行裕度的固定参考向量。

输出包括带 Lambert 着色的椭圆管、三条随标架推进的螺旋纹理，以及红/紫截面主轴箭头。所有 3D 片段按深度排序。

## 运行

```bash
go run .
```

生成：

- `artifacts/frame-comparison.svg`：三标架渲染对比。
- `artifacts/report.md`：曲率、正交误差、闭合残差和扭转指标。

验证：

```bash
go test ./...
go vet ./...
```
