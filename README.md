# CAD LOD 弦高预算示例

零第三方依赖的 Go 示例：对同一张双三次 Bézier CAD 曲面生成近、中、远三档三角网格，并使用共享顶点和细边到粗边的拉链三角形消除跨级裂缝。

## 运行

```bash
go run .
```

程序会在 `artifacts/` 下生成：

- `near.ppm`、`mid.ppm`、`far.ppm`：三档轨道视角渲染图。
- `lod_boundary_highlight.ppm`：近/中、中/远 LOD 边界红线高亮。
- `metrics.json`：三角形数、顶点数、弦高、轮廓偏差和裂缝指标。
- `lod_report.md`：面向复核的 Markdown 汇总。

## 方法

- 每档网格使用固定弦高预算，程序运行时验证最大弦高不超过预算。
- 完整 LOD 网格沿参数 `u` 划分为近、中、远三个区域。
- 每段过渡区把细边界的两个边段缝合到粗边界的一个边段，内部边均为二邻接。
- 最大轮廓偏差同时输出毫米和投影像素两种口径。
- 裂缝长度基于半边统计：忽略参数域四条外边，缝合后非二邻接边长度必须为零。

当前三档预算分别为 `0.0005 mm`、`0.002 mm`、`0.008 mm`，网格规模为 `96×64`、`48×32`、`24×16`。
