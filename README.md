# colorlab

仅使用 Go 标准库实现的 sRGB、Rec.2020、PQ（ST 2084）与 HLG（BT.2100）
正反向转换和彩条验收工具。

## 运行

```sh
go test ./...
go run . -out out
```

可选参数：

```text
-out     PPM 和报告目录（默认 out）
-cell    每个色块边长，单位像素（默认 64）
-gutter  拼图各带之间的黑色间隔（默认 4）
```

命令成功时退出码为 0；任一转换峰值误差超过 `1e-9`，或任一传递函数在
`[0,1]` 上失去单调性/端点错误时返回 1。

## 空间约定

- sRGB：IEC 61966-2-1 传递函数与 sRGB 原色，D65 白点。
- Rec.2020：BT.2020 0.45 OETF 与 BT.2020 原色，D65 白点。
- PQ：ST 2084 EOTF/OETF，BT.2020 原色；线性 1.0 表示 10000 cd/m²。
- HLG：BT.2100 HLG OETF 及其逆函数，BT.2020 原色；使用场景线性值。

所有有向转换共用同一条工作路径：

```text
encoded RGB -> native linear RGB -> XYZ(D65) -> linear Rec.2020
```

矩阵由明确的 sRGB、BT.2020 原色矩阵求逆和相乘得到。`colorlab/transfer.go`
中的分段点经过连续性处理，sRGB 使用 12.92/1.055 曲线的精确交点，HLG
使用与端点及 1/12 接缝一致的常数，避免检查时出现伪单调性问题。

## 输出

| 文件 | 内容 |
| --- | --- |
| `reference_srgb.ppm` | sRGB 参考彩条 |
| `encoded_srgb.ppm` | 四个空间各自的完整编码图 |
| `encoded_rec2020.ppm` | 同上 |
| `encoded_pq.ppm` | 同上 |
| `encoded_hlg.ppm` | 同上 |
| `chain_A_to_B_to_A.ppm` | 12 条有向回程链的三段式拼图 |
| `report.txt` | 峰值误差、8-bit 误差与单调性结果 |

每条链的拼图包含三带：

1. 源空间中的参考彩条。
2. 正向转换到目标空间后的编码值。
3. 再转换回源空间后的结果。

PQ/HLG 编码值直接作为 PPM RGB 字节写出，因此中间带看起来偏暗是预期现象；
第三带应与第一带一致。每个彩条固定包含 11 级中性灰、11 个主色/间色柱和
11 个肤色贴片。

## 误差与边界检查

峰值误差在连续值上计算，避免 8-bit 量化掩盖矩阵或传递函数错误。报告同时
给出量化后的实际 8-bit 峰值；贴近四舍五入中点的值可能出现 1 LSB 差异。

单调性检查覆盖每个空间的编码和解码函数，采样 `[0,1]` 内 65537 个等距点，
并额外加入 sRGB、Rec.2020、HLG 分段边界及其相邻浮点数。报告中的
`max_backtrack` 是最坏回退量，超过 `1e-12` 才判定失败。
