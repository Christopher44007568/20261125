## stereocheck

双目非对称投影矩阵校验工具（仅 Go 标准库）。

- 由左右眼内外参数生成离轴（off-center）投影矩阵：焦距相同但主点偏移 → 视锥非对称；平行光轴 + 视锥平移实现会聚，无 toe-in 旋转。
- 独立几何参考（纯向量运算，不经过任何矩阵）与矩阵反投影逐点比较：屏幕四角、四边中点、中心，覆盖近平面、远平面和会聚平面（屏幕边缘）交点。
- 扫描瞳距 / 会聚距离 / 宽高比，断言视差符号（`ndcX_L - ndcX_R`：近于屏为正、远于屏为负）不翻转。
- 输出每眼 4x4 矩阵、视锥边界、每眼最大角度误差，末尾汇总失败样例；有失败时退出码为 1。

运行：`go run .`　测试：`go test ./...`
